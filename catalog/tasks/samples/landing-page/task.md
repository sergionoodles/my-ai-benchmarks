# Landing page task

Build a single-file responsive product landing page for a fictional CLI tool called "Beacon".

Requirements:
- Output file: `preview.html` in the workspace root (self-contained, inline CSS/JS only, no external network deps).
- Sections: sticky nav, hero with headline + CTA button, 3 feature cards, pricing teaser, footer.
- Must work when opened via `file://` and inside a sandboxed iframe.
- Keep it under ~30KB.

We care about taste: spacing, typography, and hierarchy matter more than feature count.
