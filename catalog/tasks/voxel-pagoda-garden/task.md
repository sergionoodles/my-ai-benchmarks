# Voxel pagoda garden

Design and create a very creative, elaborate, and detailed voxel art scene of
a pagoda in a beautiful garden with trees, including some cherry blossoms.
Make the scene impressive and varied and use colorful voxels.

## Output

- Output file: `preview.html` in the workspace root — a **single,
  self-contained HTML file** with inline CSS/JS only and **no external
  network dependencies** (no CDN links, fonts, images, or fetches).
- Libraries are allowed **only if inlined** into the file (e.g. paste a
  minimal isometric/voxel renderer or write your own with Canvas 2D / WebGL).
- Must work when opened via `file://` and inside a sandboxed iframe
  (no localStorage, cookies, geolocation, or network access).
- Keep it under ~200KB so it stays snappy in the results site.
